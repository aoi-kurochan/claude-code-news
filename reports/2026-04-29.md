# Claude Code ニュースレポート 2026-04-29

## 最新ニュース・アップデート

### Claude Opus 4.7 が Max / Team Premium のデフォルトに
2026年4月のアップデートで、Claude Opus 4.7 が Max および Team Premium プランのデフォルトモデルになりました。
コーディング作業向けに新しい `xhigh` effort レベル（high と max の中間）が推奨され、`/effort`、`--effort`、モデルピッカーから選択できます。インタラクティブな effort スライダーも追加され、状況に応じてリソース割り当てを調整できるようになっています。

### Routines（クラウド実行のスケジュールタスク）が研究プレビューで登場
2026年4月14日、Claude Code に **Routines** 機能が追加されました。指定したプロンプトをスケジュール（毎時／毎晩／毎週）、GitHub のリポジトリイベント（webhook 経由）、または独自コードからの API トリガー（HTTP エンドポイント＋bearer トークン）で実行できます。
- Anthropic 管理のクラウドインフラ上で動作するため、ローカル PC をオンラインにしておく必要がありません。
- 既存の Scheduled Tasks は自動的に Routines に移行されます。
- 1日あたりの実行上限：Pro = 5回、Max = 15回、Team / Enterprise = 25回。

これで Claude Code のスケジューリングは3階層構成になりました：CLI の `/loop`（セッションスコープ）、デスクトップの Scheduled Tasks（ローカル永続化）、Cloud Routines（Anthropic 管理）。

### Ultraplan / Ultrareview のクラウド連携が強化
- **`/ultraplan`**：ローカル CLI の計画タスクをクラウド上の Claude Code on the web セッションに引き渡し、計画生成中もターミナルで別作業ができます。生成後はブラウザで該当箇所にコメント・修正依頼を行い、「クラウドで実装」または「ローカルにテレポートして実装」を選択可能。要件は v2.1.91 以降 + Claude Code on the web アカウント + GitHub リポジトリ。
- **`/ultrareview`**：本番マージ前の差分に対し、複数 AI が並列でバグ・設計の穴・セキュリティ懸念を多視点でレビューするクラウド型コマンド。検出のみで修正は別コマンド。Pro / Max は 2026年5月5日まで無料3回（1回限りの配分、リセットなし）。

### CLI ネイティブバイナリ化と Monitor ツール
- CLI が**ネイティブバイナリ**に移行し、コールドスタートとスクロール体験が改善。
- 新ツール **Monitor** がバックグラウンドイベントを会話にストリームし、Claude がログを tail してリアルタイムに反応できるようになりました。

### コマンド・UX の整理
- `/cost` と `/stats` が **`/usage`** に統合（消費要因が一目で分かる）。
- `/theme` から名前付きのカスタムテーマを作成・切り替え可能に。
- vim の **visual mode (`v`)** と **visual-line mode (`V`)** が追加され、選択／オペレーター／視覚フィードバックに対応。
- フックから MCP ツールを `type: "mcp_tool"` で直接呼び出せるように。
- `/team-onboarding` コマンド追加（v2.1.101）。

### 音声入力（STT）の言語拡充
新たに 10 言語が追加され、計 20 言語に対応：ロシア語、ポーランド語、トルコ語、オランダ語、ウクライナ語、ギリシャ語、チェコ語、デンマーク語、スウェーデン語、ノルウェー語。

### 4月のリリースペース
3月〜4月にかけて Claude Code は **v2.1.69 → v2.1.117** へと、約5週間で30回以上のリリースを重ねる過去最高ペースに。後半（v2.1.113〜117）は MCP 起動の高速化、モデル選択の永続化、`/resume` のパフォーマンス改善などに注力。

## 活用事例・Tips

### 業務自動化の実例
- **営業部門の Excel 集計**：手作業 3時間 → 14分（**93% 短縮**）。
- **経理部門の請求書 PDF 一覧化**：4.5時間 → 35分（**87% 短縮**）。
- 開発系7・ビジネス系6・クリエイティブ系4・運用系3 の全25ユースケースが実用段階に。

### TVer での大規模プロジェクト活用
プロジェクト固有の作業手順を **Skill** として定義することで、誰でも同じ品質・同じ手順で作業できる体制を構築。不具合分析から PR 作成までの一連の流れをスキルとして標準化し、チーム全体で再利用しています。

### Tips：押さえておくべき使い方
1. **`/init` で CLAUDE.md 自動生成**：`package.json` / `tsconfig.json` / ESLint 設定を解析してプロジェクト固有の指示を自動作成。
2. **テスト駆動 (TDD) との相性が良い**：先にテストを書いてから実装させるフローで品質が安定。
3. **`/ultrareview` をマージ前のゲートに**：差分のみを多視点レビュー。Pro/Max の無料枠は 5/5 まで。
4. **Routines で夜間・週次タスクを自動化**：ナイトリー Issue トリアージ、週次 PR スキャン、ドキュメント鮮度チェックなどに最適。
5. **`/effort xhigh` を複雑な設計・リファクタに**：Opus 4.7 の能力を引き出す推奨設定。
